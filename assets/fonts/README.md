# Tuffy font

`Tuffy.ttf` is the unmodified Tuffy 1.1 regular font by Thatcher Ulrich, copied from `examples/text/resources/tuffy.ttf` in the official SFML 3.1.0 package. It is used for Beltbound's debug overlay.

- [Author and public-domain release](https://tulrich.com/fonts/)
- [SFML 3.1.0 example asset attribution](https://github.com/SFML/SFML/blob/3.1.0/examples/asset_licenses.md)
- [Bundled license notice](Tuffy-LICENSE.txt)

SHA-256: `531b0148e9e700ca4ad91eda038bed432074af6c544cae8e9a0433c8f544c9a2`

The build script copies this folder beside the executable under `assets/fonts/`; no system font installation is needed.
